# Roadmap

- [x] Establish brief, vocabulary, provisional rules, AI instructions.
- [ ] Resolve open combat and turn-order rules.

- [ ] Validate card schema.
- [ ] Implement elemental modifiers, turn state, Flux, draw, movement, targeting, combat, defeat, and win conditions.

## Phase 3: Balance
- [ ] Run repeatable matches and record logs.
- [ ] Test first-player advantage and direct-attack damage.
- [ ] Adjust costs/stats based on evidence.

## Phase 4: 3D presentation
- [ ] Three.js board and original voxel model families.
- [ ] Summon, move, attack, hit, defeat feedback.
- [ ] Performance and reduced-effects options.

## Phase 5: Decks and online play
- [ ] Deck validation and local saves.
- [ ] Accessibility settings and optional match history.
- [ ] Separate security/architecture plan before authoritative multiplayer.
