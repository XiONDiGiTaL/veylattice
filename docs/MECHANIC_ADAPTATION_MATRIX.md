# Mechanic Adaptation Matrix

Maps reference research to original Veylattice implementations. Reference
behavior is cited from [REFERENCE_RESEARCH.md](REFERENCE_RESEARCH.md); "Observed"
means verified in the shipped reference data, "Inference" means a design
conclusion, never a claim about the reference's code.

Status values: **Implemented** (in the current engine, tested), **Proposed**
(specified only), **Blocked** (needs another system).

## Cross-cutting decisions recorded here

1. **One authoritative rules module.** Elemental math lives in
   [elemental-rules.js](../src/game/elemental-rules.js); the HUD only previews
   it. This supersedes the old "halve Guard" comparison (see
   [ELEMENTAL_SYSTEM.md](ELEMENTAL_SYSTEM.md)).
2. **Commands, not mutations.** Every player action is a typed command that is
   validated against ownership, timing, cost, target legality and state
   version; rejected commands return the original state by reference
   (`applyCommand`). This is the same surface a future AI, server or lobby will
   use.
3. **No reference content.** No reference card text, art, names, formulas or
   code was copied; all Veylattice names, numbers and descriptions are original
   and already present in `src/cards/starter-set.json`.
