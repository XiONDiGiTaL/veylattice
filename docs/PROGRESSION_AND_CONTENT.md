# Collection, Economy, Packs and Expansion Pipeline

Status: feature requirements with proposed tunable prices/rates. No real-money purchases or cash-out are specified.

## Currency and Stash
Proposed name: Lattice Shards. Earn from eligible validated matches; spend on packs and Singles; receive from recycling. Stash has no gameplay quantity cap. Store counts by canonical card ID and finish, plus permanent discovery history. A player may own any quantity but deck at most three copies. Rare presentation never hides rules text or changes a duplicate's canonical identity.
Recycling destroys only explicitly selected owned copies and credits Shards atomically. Show quantity, rarity, payout and resulting balance before confirmation. Default bulk recycle retains three copies per canonical card and protects quantities required by saved decks, favorites and locked cards. Manual removal that would invalidate a saved deck must be blocked until that deck is edited; server repeats validation. Initial bound starter cards cannot be recycled (proposed anti-reset-farming policy).

## Rarity and six-card packs
Exactly six cards: five Common slots plus one Rare-or-better slot. No rank upgrade may change the five Common slots. Preserve existing rarity values common, uncommon, rare, epic, mythic; launch pack manifests exclude Uncommon because the requested composition has no Uncommon slot. Existing Uncommon cards may be starter/earned/Singles eligible; do not silently relabel stable definitions.
Server RNG first selects the Rare+ tier, then a weighted eligible card within its tier. Each slot samples with replacement; duplicates are allowed and always add to Stash. Validate nonempty pools, weights and finite positive odds before publishing. Rank modifies the Rare+ tier table only. Proposed rates (Rare/Epic/Mythic): Unranked 90/9/1%; Bronze 88/10.5/1.5%; Silver 85/13/2%; Gold 82/15/3%. Always exactly 100%. Rare+ is guaranteed, not necessarily exactly Rare. Rank is current active-season rank at purchase commit, never the browser's claimed rank.
Show exact per-card odds derived from tier and within-tier weights, pack contents, price and duplicates policy before purchase. Server stores pack version, odds snapshot, season rank, rolled cards and operation ID; retries return the same opening rather than rerolling or recharging. No paid rerolls/pity system is assumed. Rare cards may offer higher ceilings/powerful Actions with appropriately higher Flux, conditions or vulnerabilities, not strictly better equal-cost Commons. Premium frames/finishes are presentation, not hidden stat boosts.

## Proposed starting economy
Pack: 300 Shards. Singles purchase/recycle by rarity: Common 60/10; Uncommon 100/15; Rare 240/40; Epic 600/100; Mythic 1200/200. Buy/recycle ratio prevents loops; Friday half-price packs must be simulated against expected recycle returns before release. Price tiers alone do not prevent stacked powerful decks: also enforce ownership, three-copy cap, curve, summon/resource constraints and counterplay.
Eligible solo base win 60, loss 15; rank win multipliers Unranked 1.0, Bronze 1.1, Silver 1.25, Gold 1.5 (60/66/75/90). Practice, AI-only observation, void/aborted games and client-only simulations grant zero. Casual tag reward policy: proposed 60 win/15 loss per participating human with same rank win multiplier, but only approved preset/server-controlled AI or validated human opponents; custom Forge decks/host-weakened AI matches are non-reward. No payout to AI seats. Server validates participation and completion, flags repeated farming, and uses configurable diminishing returns after unusually frequent eligible matches. Do not reward actions that prolong matches. Publish any limits clearly. These values are starting proposals requiring simulation and telemetry, not final economy guarantees.

## Singles and weekly shop
Singles is a shop side tab listing cards previously discovered by the player, including cards since recycled to zero. Availability may rotate, but discovery is necessary and never inferred solely from current quantity. Display owned/in-deck counts, rarity, price and any purchase restrictions. Newly released undiscovered cards cannot be bought as Singles.
Weekly rotation at Monday 00:00 UTC from versioned eligible packs; use server time and persist the chosen offer list. Proposed Friday promotion: 25% weekly chance of a Friday sale; when enabled select one eligible pack uniformly, price 50% off from Friday 00:00 to Saturday 00:00 UTC. Selection/chance are proposed defaults implementing occasional discounts, not a guaranteed weekly sale. Never reroll on refresh. Show countdown and exact price. Exclude introductory or already-discounted packs to prevent stacking. Transactions pin offer version/time and return price-change errors before charging. Old pack versions remain referenced by completed transactions.

## Data-driven expansions
Use immutable IDs and versioned JSON manifests for sets, cards, packs, effects, AI decks, assets and shop schedules. Suggested card fields: schemaVersion,id,setId,category,name,element,subtypes,cost,attack,guard,movement,range,rarity,origin,effects,modelId,portraitId,visualBriefId,loreBondIds. Runtime remainingGuard/owner/instanceId never go in printed definitions.
Pack manifests declare common pool, Rare+ pools, per-card weights, allowed ranks/odds profile, price, release window and asset version. Effects use allowlisted typed opcodes with timing/targets/parameters, not eval or dynamic scripts. New cards using existing opcodes ship through data/assets without core changes. A new mechanic needs a reviewed handler and tests; no schema promises arbitrary mechanics for free.
Author workflow: add unique ID -> validate schema/references/rarity -> author bespoke visual brief and asset -> define effects/text -> build AI/prebuilt examples -> run rules/deck/pool/odds tests -> simulate economy and matchups -> update release notes -> publish versioned manifest. Pin content/rules versions for active matches; never mutate a live match's card stats midgame. Existing saves retain stable IDs; retired cards stay in Stash/Codex and need an explicit format policy rather than silent deletion.

## Required tests
Every pack has six cards and five Commons; Rare+ rates sum to one; weighted boundary tests and seeded distribution checks; no negative wallet/inventory; duplicate/concurrent purchases settle once; recycled discoveries stay unlocked; saved-deck copies cannot be destroyed; client price/rank/outcome forgery fails; rank reset/promotion idempotency; UTC Friday/Monday/month boundaries; discount/recycle arbitrage; ownership across card finishes.
