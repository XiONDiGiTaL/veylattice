# Combat Rules

**Provisional.** Proposed resolution: (1) verify attacker ownership and attack availability; (2) verify target and range; (3) calculate effective Attack and Guard using the elemental module; (4) if Attack > Guard, defeat the defender, otherwise it survives; (5) mark the attacker as having attacked and return a structured result.

Decisions still required: defender counterattack, persistent damage vs one-time comparison, whether move and attack order is flexible, when defeated units leave play, ordering of simultaneous effects, direct attack damage, and targets becoming illegal during effect chains. Do not silently decide these in unrelated card code. Document decisions and add tests.
